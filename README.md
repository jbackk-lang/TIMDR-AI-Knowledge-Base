The search API requires a private token. The static knowledge hub is public-source documentation, **not** a public search API or deployed chatbot. The HTML page must be separately published (e.g. GitHub Pages) before search engines can index it as a website.

**Research integrity:** indexed content includes project hypotheses, formal definitions, implementation code and reported tests. Indexing does not independently validate scientific claims. Always inspect original sources and their validation status.

**Security:** never commit bearer tokens, API keys, or encrypted local credentials.
